# Security review

## Controls present

- RDS is encrypted, not publicly accessible, and reachable only from the API
  security group.
- Database credentials are generated by Secrets Manager and injected as
  separate ECS secrets; they are not committed or placed in task-definition
  plaintext.
- ECR tags are immutable, image scanning is enabled, and old images expire.
- API and Nginx containers run as non-root users.
- CloudFront is the HTTPS entry point. The ALB forwards requests only when the
  CloudFront origin-verification header is present.
- The S3 frontend bucket blocks public access and grants read access only to its
  CloudFront distribution through Origin Access Control.
- Task and execution IAM roles are separate. The task role has no AWS
  permissions; the execution role can read only the database secret in addition
  to the standard ECS execution policy.
- Logs omit request bodies, credentials, and database URLs.
- Candidate-window work is bounded, provider calls have timeouts, and missing
  forecast data fails closed.
- Dependency versions are pinned. Backend and frontend quality, dependency,
  image, and CloudFormation checks are automated in CI.
- Destructive teardown and billable deployment scripts require explicit
  environment-variable confirmations.

## Accepted MVP risks

- There is no authentication or authorization. Do not expose this write API for
  real operational or multi-user use.
- The API task uses a public subnet to avoid portfolio-scale NAT cost. Security
  groups block direct inbound access, but private subnets plus NAT or VPC
  endpoints are preferred for a genuine production workload.
- The CloudFront-to-ALB header is defense in depth, not identity-based origin
  authentication. Rotate it on each deployment.
- RDS is Single-AZ and retains one day of automated backups. This controls cost
  but does not meet high-availability or disaster-recovery requirements.
- Alarms have no notification action because no operator email or incident
  destination has been supplied.
- Open-Meteo availability and forecast accuracy are outside this system's
  control.
- Rule thresholds are prototype policy, not certified aviation guidance.

## Before broader exposure

Add identity and authorization, rate limiting, WAF rules, private Fargate
subnets, Multi-AZ RDS, longer tested backups, secret rotation, alarm
notifications, an incident runbook, audit trails, and a formal threat model.
